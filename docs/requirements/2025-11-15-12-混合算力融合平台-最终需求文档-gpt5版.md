## 1. 目标与范围
- 核心目标
  - 云端按需调度本地台式机CPU/GPU算力，完成AI推理、图像/视频处理、数据分析等。
  - 以低成本、可观测、可演进的方式达成混合算力能力。
- 范围
  - 任务分流与调度、远程执行、结果回传、数据/对象传输、观测告警、异常与降级。
- 非范围
  - 大规模分布式训练、跨云跨区容灾、跨国合规（可另立项目）。

## 2. 总体架构（独立）
- 三层结构
  - 网络层：Tailscale/Headscale（优先）或自建WireGuard。
  - 调度层：轻量Agent/调度器（路由、排队、限流、重试、降级）。
  - 协议层：MCP微服务化（按功能拆分MCP Server）。
- 平面分离
  - 控制平面：Agent↔MCP指令/会话。
  - 数据平面：大对象经对象存储（MinIO/S3）预签名URL旁路。

## 3. 服务器侧与本地侧（差异化职责）
- 服务器侧（云）
  - 调度/网关、队列（NATS/Redis Streams）、对象存储预签名服务、鉴权与令牌签发、观测与告警、SLO守护、降级回退、对外API与流量控制。
- 本地侧（台式机）
  - VPN常连、MCP执行面（llm-inference/image-generation/data-processor/vector-search等）、容器运行与GPU调度、模型/数据热缓存、结果回传、节点/GPU指标导出、自愈。

## 4. 网络与安全
- 可达性
  - 首选：Tailscale/Headscale（零配置NAT穿透）；备选：WireGuard(UDP)+DDNS+Keepalive。
  - 可用性：常驻出站轻代理；可选WoL中继或Intel AMT带外。
- 安全边界
  - 隧道+应用双层鉴权：VPN + mTLS或短TTL JWT。
  - SSH仅应急跳板：MFA+JIT+审计+源IP限制；严禁常态化。
  - 密钥/证书：轮换≤90天，集中吊销；审计范围（鉴权/任务/数据访问）留存≥180天。

## 5. 端口与ACL实表（执行口径）
```yaml
# 方向：Ingress=入站到云；Egress=出站自云或本地
rules:
  - name: vpn-wireguard
    proto: udp
    port: 51820
    direction: Ingress (cloud)
    source: vpn_peers_cidr  # Tailscale/Headscale控制面或peer网段
    action: allow
  - name: mcp-gateway
    proto: tcp
    port_range: "2470-2499"
    direction: Ingress (cloud)
    source: vpn_cidr_only
    action: allow  # 仅内网访问；对公网关闭或置于反代+WAF
  - name: nats
    proto: tcp
    port: 4222
    direction: Ingress (cloud)
    source: vpn_cidr_only
    action: allow
  - name: redis-tls-optional
    proto: tcp
    port_list: [6379, 6380]
    direction: Ingress (cloud)
    source: vpn_cidr_only
    action: allow
  - name: minio
    proto: tcp
    port_list: [9000, 9001]
    direction: Ingress (cloud)
    source: vpn_cidr_only
    action: allow
  - name: observability
    proto: tcp
    port_list: [9090, 4317, 3100]
    direction: Ingress (cloud)
    source: vpn_cidr_only
    action: allow
  - name: ssh-admin
    proto: tcp
    port_list: [22, 2222]
    direction: Ingress (cloud)
    source: admin_whitelist_ip
    action: allow  # 强制限源；默认对公网关闭
  - name: egress-default
    direction: Egress (cloud/local)
    dest: vpn_cidr_only
    action: allow  # 本地侧尽量仅出站必要端口
```

## 6. 作业编排与可靠性
- 队列与协议：NATS JetStream（优先）或 Redis Streams（消费者组+ACK）。
- Job状态机
  - Queued → Running → Succeeded/Failed → DeadLetter
  - 字段：job_id、idempotency_key、priority、ttl、attempts、state、timestamps、input_ref、output_ref、error_code。
- 幂等与容错
  - 幂等键去重、ACK语义、指数退避重试、DLQ；熔断与快速降级到云端轻量能力。
- 资源控制
  - 并发上限、优先级/配额、背压；任务超时与抢占。

## 7. 数据与模型传输
- 大对象旁路：MinIO/S3 预签名URL；分片/断点续传、压缩；MCP仅轻载荷（建议<1MB）。
- 缓存分层：本地NVMe热缓存（模型/常用数据）、对象存储温层、冷数据归档。
- RAG：向量检索驻留远端节点，云端仅传查询与Top-K结果。

## 8. 观测与最小告警（MVP即上线）
- 指标采集：Prometheus + Node/GPU Exporter；队列深度、端到端P95、成功率、网络RTT/丢包、缓存命中。
- 最小告警阈值
  - 失联：节点/心跳缺失≥3次采样（≤5分钟）。
  - 失败率：>1%（5分钟）持续2个周期。
  - 队列积压：深度P95超过设定阈值持续≥5分钟。
  - 端到端P95超目标：连续3个检测窗口。
- 仪表盘：调度SLO、资源利用、失败热点、网络质量。

## 9. SLO与验收
- 可达率：远端可达≥99.5%（VPN稳定≥72h）
- 成功率：≥99.0%，死信率<0.1%
- 端到端P95：按任务分档（示例：LLM推理≤2.5s/512tok；图像生成≤40s/512x512）
- 缓存命中：≥80%（稳定期）
- 灾备：RPO≤15min，RTO≤30min
- 安全：密钥/证书轮换≤90天，审计可追溯率100%

## 10. 环境与可用性（矩阵与SOP）
- GPU/驱动/CUDA/cuDNN矩阵
  - 统一在镜像中固化；提供“当前/上一稳定”双版本以便5分钟回滚。
  - 示例：CUDA 12.1 + cuDNN 9.x + Torch 2.1；需按实际GPU型号确认兼容。
- Windows路径（如适用）
  - Windows + WSL2 + NVIDIA驱动 + CUDA toolkit + nvidia-container-toolkit；提供安装验收SOP与回滚脚本。
- 本地可用性
  - UPS（≥30分钟）、系统自启、服务自愈（探针触发重启/摘除/重排）。

## 11. 成本核算口径与KPI
- 单任务成本（近似）= GPU电力成本 + 带宽/出网费 + 对象存储读写与容量 + 设备折旧
  - 电力：功耗(kW) × 时长(h) × 单价
  - 出网费：传出流量(GB) × 单价
  - 存储：请求数/GB × 单价
  - 折旧：硬件成本/折旧周期 × 使用占比
- 报表周期：周报/月报；KPI：成本优化≥30%，GPU利用率目标区间（避免长期<20%或>95%）。

## 12. 部署策略与工具链
- 容器：Docker + nvidia-container-toolkit；Compose优先，避免过早引入K8s复杂性。
- 配置管理：Ansible或轻量脚本化。
- 文档化：C4/C3架构图、OpenAPI、端口/ACL实表、版本矩阵、Runbook与应急手册。

## 13. 里程碑与验收（快闭环）
- P1 连通与安全（T+2周）
  - 交付物：网络拓扑图、端口与ACL实表、安全策略与轮换流程。
  - 验收：VPN稳定≥72h、可达率≥99.5%；应用层mTLS/JWT生效；心跳与基础指标可见；SSH仅应急策略落地；安全组收敛。
- P2 最小可用闭环（T+4周）
  - 交付物：首个MCP原型（llm-inference或data-processor）、队列与Job契约、对象存储旁路(预签名URL)、基线压测与仪表盘。
  - 验收：端到端成功率≥99%、P95达标；大对象不经MCP直传；幂等/ACK/退避/DLQ生效。
- P3 可靠性与扩展（T+6~8周）
  - 交付物：灰度/回滚与熔断/降级、模型缓存策略、告警规则与Runbook、（可选）OTel追踪。
  - 验收：（可选）追踪覆盖≥95%；缓存命中≥80%；回滚<5分钟。

## 14. 风险与缓解
- 网络抖动/不可达：多链路/自动重连；快速降级至云端轻量推理。
- 秘钥泄露：短TTL、集中吊销、最小权限、审计与告警。
- 大对象阻塞：预签名URL旁路、分片/压缩、就近缓存。
- 版本不兼容：SemVer、契约测试、金丝雀与回滚。
- 家庭可用性：UPS、自启/自愈、带外访问（AMT可选）。

## 15. 交付物清单（执行检查表）
- 文档：架构设计、网络拓扑、端口与ACL实表、组件版本矩阵、接口契约、SLO表、运行手册、应急Runbook、审计与安全策略、性能与成本报告模板。
- 代码/配置：MCP Server样板、队列集成、对象存储集成、监控/日志/告警配置、自动化部署脚本、端到端测试与基准压测用例。

## 16. MVP前置P0清单（启动门槛）
- 安全组收敛（22/2222限源或关闭、非必要端口关闭、MCP内网或反代+WAF）。
- SSH仅应急（MFA+JIT+审计+源IP限制）。
- 队列健壮性（NATS JetStream或Redis Streams）：幂等键、ACK、退避重试、DLQ、状态机字段。
- 数据通道旁路（MinIO/S3预签名URL，MCP轻载<1MB）。
- 最小观测与告警（Node/GPU、队列深度、端到端P95、失败率；阈值固化）。
- 审计与密钥治理（轮换≤90天、吊销、留存≥180天）。
- 环境与可用性（GPU矩阵与回滚镜像、UPS、自启/自愈SOP）。
